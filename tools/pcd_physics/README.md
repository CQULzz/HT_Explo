# 独立接触动力学核验

用户要求检查HT/几何冲突位置实际上是否能通过。这里不修改TARE/HT导航代码，也不把CMU直接积分速度的穿越作为物理证据。

本机工作目录：`/home/lzz/pcd_physics_20261110`。按归档Scout SDF的碰撞几何、质量、惯量、轮关节与80Nm力矩限制生成URDF；场景直接从原始Collada导出三角形，不用HT/terrain_map生成地面，不添加地图外平面。使用PyBullet3.2.7 DIRECT，重力与轮地接触驱动车身，仅初始化时设置位姿。

先保留平面与原地图起点控制试验。正式诊断固定10组代表冲突位置/方向，分别做中心稳定支撑、前进穿越和倒车穿越；每个方向从中心前/后0.8m开始，以0.2m/s通过，总长1.6m。起点2s稳定、12s驱动、1s停止；起点轮位无测量地面时记为不确定，不改起点或补地面。越过时的中心横向误差≤0.1m、车头误差≤15°，另记录车底接触、穿透、倾覆和失去支撑。未稳定接地或没有穿过不等同已证明任意路线不可达。

三种预先固定摩擦模式用于灵敏度：近似旧场景的纵向0.8/侧向0.1，以及各向同性0.4、0.8。原ODE滑移参数无法直接等同于Bullet，摩擦未实车标定。Scout车体0.925×0.38×0.21m、轮半径0.16459m，与此前CMU简化车体不同。结论只适用于该归档车辆/重建网格和这些假设，不作真实车辆通行保证。

每个试验保留RESULT、20Hz状态/关节/接触CSV。该批是独立局部物理判据诊断，不是新的导航优化候选；局部动力学试验不冒充600秒闭环探索验收。代码/资产/参数先冻结，不在批内修改。完整数据不创建Release、不清理；原始导航分支不动。
