# Scout Jetson 更新：2026-10-23

分支：`real/scout-helios32`。标签：`scout-helios32-2026.10.23-startup-prior-v1`。
本版本基于e0e09ce，包含当前Jetson实车适配、性能优化、命令适配器和起点先验配置；不是实车自动驾驶验收版本。

## 当前行为

- 独立build_real/install_real；ROS Humble、ARM64及本机OR-Tools路径支持；HT终端不混用传感器工作区环境。
- 实车入口CUDA严格FP32、NCHW；异步接收保留最新待处理地图。时间/定位故障仍拒绝发布，源时间戳与地图TTL不放宽。
- 可选Numba质量过滤，串行、fastmath=False，保留NumPy参考路径及缺依赖回退；启动前预热。
- 可选TwistStamped到Twist命令适配器，带时效、输入所有权、急停和速度限制。跟踪器与适配器默认关闭，HT方向校准默认false，探索不自动开始。
- 用户要求启用固定起点1.2m半径、30s的未知支撑先验。完整车身仍需通过检查，已知障碍或低概率优先拒绝。先验不跟随车辆、不写回测量、不关闭自身点云过滤。
- RViz的0.6m白圈仅为诊断范围。HT输出241×241@0.04m，约9.64m见方；无效预测保持空白。实测高程颜色表示高度，不能当作通行概率。

## 已有验证及限制

- 最新Python回归157项通过；原有C++回归84/84通过。此次启用先验另运行既有起点边界/障碍优先与严格未知策略测试，2/2通过。
- 同8帧真实输入对照，全部12个输出层数值/NaN掩码完全一致。质量过滤优化后完整回调均值0.369→0.238s；25s静态实时观测约3.60Hz，不宣称10Hz。
