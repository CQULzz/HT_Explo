# 近车陈旧高程处理（2026-11-01）

本机实包发现：近车原生高程图保留约96秒前的高点，高出附近地面约0.78/1.02米；过滤后的同帧点云没有更新这些位置。部分车体盲区观测已超过历史层600秒有效期。有限高度被拒绝后转为障碍、或过期地面使整个51×51上下文无效，都会影响起步。

## 当前实车策略

`ht_qualify_evidence=true`，`ht_stale_surface_s=5.0`，`ht_surface_margin_m=0.15`。这些值是显式工程参数，不是新的现场标定或地形验收结论。通用独立HT节点默认不启用；实车launch默认从`ht_real.yaml`读取，可用`qualify_evidence:=false`作旧逻辑对照。

- 历史窗口记录实际选中表面/障碍的观测时间，不能把另一层地面的时间或新消息到达时间当成它的新观测。
- 新鲜且通过质量检查的高度原样进入模型。被拒绝的高度只有仍新鲜、且明显偏离地面参考时才保留为确定障碍；新鲜正台阶、负障碍继续受到检查。
- 超过5秒、偏离地面参考超过0.15米的旧高度，以及其他不确定高度，退出模型的已知高度集合。旧的可信平面地面仍遵循原历史有效期。
- 被移出的格子记录在`ht_uncertain_evidence`，其`ht_valid`和`ht_observation_valid`均为0，并禁止小孔插补。这是未知，不是已测自由地面。
- 旧地面过期不再因一个格子否决整片神经网络上下文；该格本身仍无效，独立的车体缺测检查继续阻止穿越。

模型输入的最近邻上下文仍只用于推理，不能增加物理观测许可。独立碰撞、未知检查、车身点云过滤、方向检查和地图时效不变；起点许可沿用用户要求的1.5米/60秒固定范围和时长。

## 建图配置与部署

`mapper_for_ht.yaml`启用`enable_visibility_cleanup=true`，关闭整片覆盖清空`enable_overlap_clearance=false`。只有当前真实雷达射线能反证的旧高点才参与清理；不按车体位置抹地，也不把没有回波的位置填成地面。

`max_ray_length=3.0`只限制清理射线长度，不缩短点云融合的测量范围。本机约43059点的分量检查，清理10米时耗时中位约117ms，改为3米约45ms；这是特定输入的分量结果，不是整链路10Hz承诺。

外部CuPy工作区保持独立；实际启动必须向外部mapper传入这些配置。本机诊断入口有独立setup文件，仅修改仓库YAML不会自动改变已启动mapper的内存参数。部署需停车后重启mapper与导航；使用新输出目录保留旧地图/日志，不将重启后地图变干净当作射线清理的独立证明。

## 已知限制

没有新测量支持的格子仍会停车，修正障碍标签不等于已经获得可执行路径。后方真实人员必须继续保留；不能把现场口头反馈直接写成平地。实包复算从记录的输入重建历史，未包含活进程之前十余分钟的完整历史，不能声称逐字节重现当时所有状态。

CUDA/CPU物理未知掩码、历史模式时间、新鲜正负障碍和小孔保护均有回归检查。本轮不将离线检查称为600秒仿真或实车自主探索验收。
