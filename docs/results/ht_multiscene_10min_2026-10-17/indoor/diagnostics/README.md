# 室内停滞的只读诊断

实际地图和控制程序未修改。`candidate_points.json` 是额外只读订阅 `/viewpoint_in_collision_cloud_` 得到的280个候选视点（该历史话题名与实际内容不一致，发布函数实际复制候选点）。

`support_audit.json` 使用与 HtCostMap 相同的0.6m车体支持半径、额外 sqrt(2)*栅格边长和未知区膨胀规则。支持的原始候选只有一个，距车不到0.8m，故没有可送入搜索的目标。

`dense_probe.cpp` 调用项目原有 planXYTheta，运动学和搜索参数不变；使用该快照的八方向膨胀掩膜，在每条短运动边上按5mm/0.01rad采样检查，验证细采样目标的可行性。它是离线诊断，未发布运动指令；不是实际ROS执行或精确DDA边界检查的替代。路线仍需独立实测。

0.6m网格在距车0.8至4m范围内没有通过支持检查的端点，0.3m网格有22个。计划在五组原参数测试结束后，仅细化室内视点配置并单独补跑600秒；保留原失败记录。
