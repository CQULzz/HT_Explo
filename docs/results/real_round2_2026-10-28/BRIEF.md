# 上一轮实验问题简报

1. **车旁盲区仍在。**55帧末帧的0.6m车旁范围共709格，554格缺物理支撑，709格HT上下文无效。它是缺测，不等于地面真实不可通行。
2. **找到自过滤框的几何问题。**现配置在雷达坐标系过滤`[-1,0.2]×[-0.7,0.7]×[-0.9,0.2]m`。按已核验外参，平地高度约为雷达下方0.785m，落在该框内；框也没有完整覆盖模型的车头。不能据此认定55帧盲区完全由它造成，但这项过滤规则确有误删地面、漏删车体的条件。
3. **观测年龄入口有冲突。**实车默认将mapper的`time`层作为观测年龄，而项目中观测年龄修复文档明确区分定时器累计的`time`与依据实际点云时间更新的`observation_age`。应使用后者，避免旧格子的时效判断失真。
4. **旧录包缺信息。**10月11日1906条高程为250×250且无观测年龄；当前291×291接口拒绝它是预期行为。补尺寸不能恢复原本没有记录的测量时间。
5. **CPU有耗时尖峰。**上一轮回调中位172.4ms、最大934.2ms。新增核对发现55次网络输入全部不同，不能使用“地图没变就跳过推理”来解释或修复本组数据的耗时。

本轮处理：依据指定仓库的车体碰撞几何与传感器模型重做自过滤；统一真实观测年龄入口；先比较推理实现与线程设置，再决定性能修改。使用同一55帧检查HT输出，用旧录包原始点云检查过滤前后差异。保留原始数据、失败记录和对比视频。当前阶段只做离线实验，不启动实车或仿真。
