# 对比视频中的地面由绿变红：纹理与坡面对换归因

用户明确来源为HT_filter_original_vs_plus20cm_RViz.mp4，未给出具体秒数。本报告核查该视频中26.607462→29.199291秒的一个可复现反例，不能冒称已逐像素定位用户截图或解释全部红块。

核心事实：世界位置(−0.48,12.24)m的51×51输入，在原过滤与额外水平20cm两套结果中完全相同；0°分数从0.981846变为0.164459，八方向均从>0.8变成<0.34。该处扩大车身过滤没有改变原生高程、历史高程、最终输入及其观测/填值掩码，因此另一类大面积低分不会因近车过滤自动消失。

这次不是只用“周围有墙”解释：后一帧整个约2.04×2.04m邻域已观测高度跨度约10.04cm，无障碍层标记；融合后的2601格中2600格有有效观测历史，仅1格需最近邻填值。这里的观测包含历史保留，不能说2600格都是此帧新测量。CuPy原生图此处2523格有限、78格缺测；前帧2319格有限、282格缺测，原生缺测反而减少。

把输入分别拟合平面，并分解为“拟合平面＋去平面残差纹理”后，固定模型和0.5阈值，单独对换两个分量：

| 输入 | 0°分数 | 八方向范围 |
|---|---:|---:|
| 实际前帧 | 0.981846 | 0.815～0.985 |
| 实际后帧 | 0.164459 | 0.164～0.331 |
| 新平面＋旧纹理（仅诊断） | 0.979640 | 0.822～0.986 |
| 旧平面＋新纹理（仅诊断） | 0.167373 | 0.167～0.329 |
| 仅新拟合平面（仅诊断） | 0.999889 | >0.9997 |
| 新纹理幅值减半（仅诊断） | 0.800551 | 0.801～0.876 |
| 新纹理0.5格Gaussian（仅诊断） | 0.676207 | 0.676～0.798 |
| 新纹理1格Gaussian（仅诊断） | 0.994804 | 0.985～0.995 |

原始51×51单patch推理与完整图的同点输出误差<1e-5。输入对换证明：这个样本的输出主要跟随细碎起伏纹理，而非前后拟合坡面差别。前后最终输入去平面RMS约1.22→1.54cm，4cm网格相邻格高差绝对值P99约2.95→4.81cm，最大约3.99→7.94cm；不能因总体RMS只差几毫米就认为空间形态没有改变。

阶段追溯：原生CuPy图对应patch去平面RMS约1.94→2.93cm，相邻格高差P99约5.43→9.64cm；历史融合后约1.32→1.71cm，最终输入约1.22→1.54cm。说明较强的起伏在原生高程阶段已经存在，后面的融合和质量处理有所降低，但没有让模型响应保持稳定。native/history阶段的T是诊断用的局部缺测最近邻补值后推理，并非原生产链在该阶段发布的T；不要与完整链的实际输出混淆。

已经解释到的层次：输入具有细碎厘米起伏而非理想平面，当前模型对这种纹理变化响应较强，8通道一起跨过分类门槛。缺测不是这个样本的主导因素，0.5也不是只有0.49/0.51小幅抖动的问题。真实墙柱附近的红色不能一并归为噪声。

仍未闭合的物理归因：这些起伏是实际小尺度地形、雷达点误差、帧内运动畸变、位姿误差，还是CuPy具体融合环节导致，尚未隔离证明。不能仅凭反事实平滑后变绿就认定“已经安全可行驶”，也不能把Gaussian整体平滑部署后称为修复：它会损害真实台阶、小物体等特征。

本轮没有改生产代码、过滤默认、阈值、权重或控制策略；只增加上下文记录、逐点比对与神经输入诊断。额外20cm结果的64帧输出逐数组与视频来源精确一致；选定两帧的6个输入/掩码层在原过滤与20cm之间逐值一致。数据见plus20/CONTEXT_VERIFY.json、LEFT_RIGHT_PATCH_MATCH.json、PATCH_PROBE.json、STAGE_PROBE.json及NPZ；全量64个新增精确上下文另行归档。原过滤精确上下文与原始数据已经在前两轮Release。

下一步应把这个固定地面窗口的高程恶化回溯至原始回波、精确采样时间和每次融合的贡献，并以真实小台阶作反例验证；若输入确实可信，再评估模型的噪声鲁棒性/训练域匹配。当前不以历史补绿、调低阈值或整体抹平来代替来源隔离。
