# 循环6实测：建图源龄改善已重复出现，探索完成仍不稳定

已完成当前用户要求的仿真测试，6/6次完整120秒，实录合计721.6秒，运行墙钟合计759.0秒（不含分析）。按照此次测试设定的6次边界停止，不继续无限试跑；原循环2账本不变。

## 可保留结论

固定当前导航/场景/配置/权重/编译产物，三对只切mapper multi/single，42首次、99及42复跑的主发布源龄P95分别降低33.42%/33.98%/47.38%。single三次P95范围0.5180–0.6420s，是否全部<1秒：True；是否全部完整/无采集错误/无非零退出/无冻结变化：True。因此新模式在这批WSL条件下通过源龄这一项验收，保留可选single模式及原逻辑修复，不回滚；实车默认入口/配置未切换或部署。

不能宣称全面探索改善：三对体积变化+54.58%/+96.62%/-41.73%，第三对退步，种子42两次变化很大。两种模式都出现评分/支撑、地图时效或无可执行路径停车；single只有一次内部完成。故整体持续探索/覆盖/全部完成验收尚未通过。

## 可比性、核验与局限

- 六次均实测同一提交7a6a773（父版本eb84799包含当前导航，ec1a145含mapper模式），所有冻结文件哈希映射完全相同，见FROZEN_EQUIVALENCE；模式环境选择及种子写入manifest与命令。顺序multi42→single42、single99→multi99，再multi42→single42复跑；只有两个不同种子和三对，不宣称统计显著或跨场景/长期/ARM普遍收益。
- 原主指标保持HT生产者1Hz性能遥测source_age_at_publish_s。各轮附全率录包端DELIVERY_AGE，只作额外诊断；mapper自身接收时源龄还受其时钟回调调度影响，不替代共同HT指标。源header及观测年龄来自真实输入，概率0.5、1秒、未知/几何门限与固定启动许可未调。
- 路径随ROS/GPU调度和重建数据变化，固定TARE/Gazebo种子不保证逐帧轨迹一致。各轮可见工作负载不同，探索量是采样LiDAR射线体素并集代理，里程含初始沉降。尤其42复跑出现体积退步，保留全部失败/坏结果，不只选好的。
- 所有轮均核对MCAP计数/可用CRC/SHA及完整视频解码，15个数组档案/轮可读取且SHA记录；这不是全频原始激光/CuPy输入的无损录制。脚本可复算，源码/配置/二进制哈希、命令、成本、原始目录在每轮EXPERIMENT_CONTEXT/manifest。
