射线和LiDAR覆盖使用雷达原点。车辆位置、栅格滚动中心、访问历史、路由、回家和起点锚点仍用车体。通用入口偏移默认为零。测试包含扫描时刻插值、roll/pitch/yaw、零偏移和非法输入。
