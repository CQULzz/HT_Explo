# 阶段38｜修复全局任务与局部窗口交接，完整车库600秒

## 改了什么

以全局单元ID及EXPLORING状态保持引导，修复“暂时退出全局巡游列表就放弃当前未完成任务”的语义错误。保留真实任务解除、到达、无进展超时与冷却、每轮路线重搜和所有HT/几何/运动硬约束。实测代码16bdbe4；5项冻结文件变化（4源/头文件+规划二进制），其余60项及实际全部参数与阶段37相同。

## 实现了什么功能

跨全局巡游→局部窗口委派继续追踪同一任务，避免反复换边与打断局部承诺。新增逐周期任务ID/tour/pending日志，本轮221个退出tour但任务未完周期保持引导；2次无进展超时仍正常释放。

单轮累计自由体积没有倒退：阶段36/37/38曲线均是单调历史并集。不同轮次路线与回访不同，最终体积会变化；不能把全部差异归因于一个机制。
