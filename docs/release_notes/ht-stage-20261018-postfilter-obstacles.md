# 阶段26｜融合后拒绝高度保留为硬障碍：仍有末段停滞

实测代码`22c2749`；室内完整600秒，失败与退步均保留。

## 改了什么

融合后质量过滤的有限拒绝高度沿用源输入已有保守规则：保留实际高度作为障碍上下文，独立障碍格八方向强制0。不有限的拒绝仍未知，保留网络窗口否决。模型权重、0.5阈值、物理足迹、3秒时效及观测时间未改。额外保存每10秒完整神经输入/输出。

## 实现了什么功能

修正一处距车1.02m的有限质量拒绝高度导致整块输入窗口未知的接口不一致；没有把拒绝点补为自由地面。七项支撑回归与真实模型ROS一帧集成检查通过，实际拒绝格八方向严格零。

## 实验与验证

600秒116.15m、1258.000m³，最终BLOCKED；上一轮65.80m、1959.875m³。里程增加但观测体积下降约35.8%，不称整体改进。最后平移约505s，最长全零95.02s。13项采集检查、600秒视频解码通过；128次晚拦截全部实际发零。

58份网络上下文与同源时间戳发布图逐值相同，三份冻结权重重放最大差0；这仅验证数据一致，不是物理真值。冻结图仅含HT的16个目标查询可达10个，更多预算/细网格仍为10，尚不能定位实际几何/短名单/失败记忆中的哪一项导致停止。

[完整报告、对比、数据与限制](https://github.com/CQULzz/HT_Explo/blob/codex/ht8dir-v1/docs/results/ht_postfilter_obstacles_10min_2026-10-18/REPORT.md)。附件含整轮已录制目录、全部神经输入、精选结果、SHA256与独立MP4。激光源秒抽样和周期地图不等于全传感器无损数据。

## 存在什么问题

末段95秒仍无路停车，地图年龄最大3.336s；有回访、体积退步。临时几何捕获没收到collision_cloud，不能冒称完整几何复现。下一轮补可靠几何记录、逐目标搜索终止原因，并核查连续碰撞检查计算代价；任何提速要验证同一碰撞判定。多场景/重复稳定性、动力学与物理标定仍未完成。
