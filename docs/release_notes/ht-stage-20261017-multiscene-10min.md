# 阶段18｜五环境各10分钟与15fps录像（执行中）

实验工具与录像协议更新，C++规划沿用`bd0c2c2`，HT桥接沿用`f1c8485`。相机升级会增加观测负载，不能直接把本轮实时性数字与原320×180/2fps记录等同。

## 改了什么

参数化仿真/规划场景，串行运行Garage、Campus、Indoor、Forest、Tunnel各600秒；原生相机960×540、15fps，裁剪初始化、编码和完整解码核验。

## 实现了什么功能

各组独立地图与进程，独立视频/数据/资源审计，完成一组退出与编码后才进入下一组；底部状态条显示时间、速度、任务和地图/相机年龄，提供播放列表和预览。

## 实验与验证

视频时间轴回归通过，未来相机帧不回填到过去；H.264裁剪/完整解码样例2秒30帧通过；首组确认原生960×540。完整五组正在执行。

[执行协议与脚本](https://github.com/CQULzz/HT_Explo/blob/codex/ht8dir-v1/docs/experiments/ht_multiscene_10min.md)。历史小时测试按用户新要求停止并保留数据，不将其标作完成。

## 存在什么问题

每环境仅10分钟，不能视作更长时间或实车稳定性证明；仍可能地图过期安全停车或BLOCKED，保留原始记录。不同场景参数与原生起点不同，不是算法优劣的公平对照。
