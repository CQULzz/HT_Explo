# 阶段39｜搜索支配边提前剪枝，以及当前HT与TARE的结构差距

## 改了什么

Hybrid A*相同终点键/代价的支配比较移到昂贵HT/几何检查之前：原来最终也会丢弃的边不再白做检查，可能进入队列的边仍按原顺序逐段硬验证。保持原语/分辨率/采样、全部阈值、候选与覆盖评分、0.15s单目标/0.35s周期预算。无跨帧缓存或量化碰撞位置。实测6fc7549，65项冻结仅规划头、调用日志和规划二进制3项改变，62项及全部实际参数相同。

## 实现了什么功能

减少重复状态边的无效硬检查，逐次输出dominated_pruned计数。冻结公开输入四目标各256展开，调用约11700→3800；18组合成障碍/方向patch/直连开关检查真实成功路线、成本与逐姿态相同。反例保留：原预算下4目标新旧各24次仍全超时，加速不代表有路。

另经代码审计说明当前与原版TARE差距：HT开启时绕过原局部多视点TSP、10轮采样变1轮，主要用单点收益/到达时间选目标；全局引导多用欧氏距离，未充分利用拓扑绕行。原版历史控制角速度/倒车/加速度更宽松，旧180秒HT51.7%不是当前版本准确比率。这些结构/条件贡献尚未消融，本轮没有修复这些覆盖决策问题。

## 存在什么问题

体积较38+11.6%，仍低于36的7900.375m³；里程、末分钟新增、完全停车占比和最长无平移有退步，仍65次超时。原局部多视点覆盖和全局拓扑接力未恢复，没有完全相同控制约束的新原版配对，不能称追平TARE。单轮、单场景，不是统计或实车验收。
