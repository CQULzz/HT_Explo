# HT + TARE 整改实现

对应 `HT_TARE_REMEDIATION_PLAN.md`；用户追加要求：默认起点附近小范围可通行。

## 起点先验与缺测策略

- 在任务开始、收到有效定位/雷达及新鲜 HT 图后，固定一次起点。坐标为零也是有效起点，不再用零向量判断是否初始化。
- 默认先验半径 **1.2 m**、最长 **30 s**；机器人离开该圆后永久停用，不会随车移动或回到起点时重置。半径设为 0 可关闭。
- 先验只补缺测：已知概率始终优先，包括低概率；不改写网络输出/有效掩码。执行状态单独报告 `STARTUP_PRIOR`，不冒充网络观测。
- 足迹支持检查仍覆盖半径 0.6 m，因此 1.2 m 先验不表示可直接向外行驶 1.2 m。
- 默认 `geometric_fallback`：当前 HT 图健康而局部缺测时，保留几何碰撞、局部范围和当前视线检查，使用不超过 **0.2 m/s**、**0.5 m** 的短航点。有效段 HT 风险仍计入，未知段保留长度罚项。
- 降级预算按整个任务累计：**60 s 或 10 m** 任一耗尽后，未知段停止执行。恢复已知支持可正常行驶，但不会充值预算。
- `strict` 保留缺测停车；仍可单独启用上述起点先验。
- 地图缺失、过期、未来时间戳、缺层/错误布局、TF 异常或未校准均停车；先验与几何降级不能绕过这些故障。声称有效的格子若概率非法，整幅消息拒绝。
- 几何降级不切换 `ht_enabled`。图和局部路由继续使用同一个 HT 分支，代价为长度 + 已知方向风险 + 未知长度罚项。
- 默认地图等待期间不移动。尚未实现无 HT 发布心跳时的启动降级，避免把节点故障误认成地形缺测。

`/speed` 发布正常/降级/停车请求，遵循 CMU 的自主模式与遥控优先规则；它不是独立硬件急停。正常速度默认 0.5 m/s，可配。上述半径、速度、预算为工程初值，不是安全理论界限。

## 返航与完成

- `/exploration_finish` 保留“探索阶段结束”含义。
- 新增 `/mission_state`：`WAIT_START`、`EXPLORING`、`RETURNING_HOME`、`BLOCKED`、`COMPLETED`；阻塞不清除返航意图。
- 新增 `/mission_completed`：必须距固定起点水平距离不超过 **0.5 m**、从连续位姿测得速度低于 **0.05 m/s**，健康状态下持续 **1 s**。
- 空路径/只有 ROBOT 点、停在外面、只发了零速度，均不算完成。
- HT 开关共用任务和返航入口，移除 HT 提前返回局部路径造成的返航遗漏，移除未经检查的近家直线航点。
- 返航先取 keypose 图路径；HT 开启时，下一段再用当前有向 HT 图求路。出发方向的低风险不能代替返回方向的风险。
- 返航检查点只向前推进；已经通过的节点不会因每轮最近点映射而重新成为目标。全局返航候选固定，HT 局部下一段和执行几何检查持续更新；若原路受阻则明确停车等待，不承诺自动解决所有动态封路。
- 每次只执行当前可见、无碰撞的短路径前缀；被挡住的首个拐点不能跳过。无可执行路径时 `BLOCKED`，不直接穿障碍回家。
- 图中没有合适高度/连通节点时返回无路径，不再默用节点 0。
- 定位/雷达新鲜度默认 3 秒，规划超过该时限无更新亦停车。预启动不再发出 12 m 无检查航点。

`/ht_execution_status` 区分 `HT_ASSISTED`、`STARTUP_PRIOR`、`GEOMETRIC_FALLBACK`、`HOME_SETTLING`、故障原因和预算耗尽等。

## 可复现验证

```bash
bash experiments/closed_loop/verify_remediation.sh experiments/results/my_remediation 90 2
```

自动构建、运行核心/ROS 回归、用原始雷达跑 TARE 与 TARE+HT、保存协议与数据并生成 `comparison.png` 和 `REPORT.md`。全程本地固定代码，不调用模型 API。

核心回归覆盖固定起点、离开/到期失效、预算不重置、到家停止确认、空/单点路径、转弯与受阻首段。ROS 测试覆盖方向风险、有效观测优先、局部缺测与全图故障区分、严格策略、布局/TF/时间戳异常。

闭环结果以结果目录报告为准；代码整改和回归通过本身不证明 HT 的道路筛选成功率提高。单个训练域山地、简化运动学车辆和少量重复仍不能替代未见地形/实车验证。

地图失联恢复回归（暂停实际推理进程，仍由真实雷达驱动仿真）：

```bash
experiments/closed_loop/run.sh --condition ht --pairs 1 --duration 35 --map-outage-at 3 --map-outage-duration 6 --output experiments/results/map_outage
```

`fault_injection.json` 记录暂停/恢复时间，检查 `HT_MAP_STALE` 时速度请求为零、禁止导航，恢复新鲜图后再继续。
