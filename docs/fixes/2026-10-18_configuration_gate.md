# 室内停滞：区分车辆配置得分与物理障碍物

上轮代码12d85d8完整运行600秒，约74秒后停在(9.133,-1.822)m，最终17.82m、778.000m³、BLOCKED。地图、定位和节点仍工作；当前姿态允许，实际搜索只展开28个状态。不同分辨率的54次同图查询全部失败，并未耗尽预算。

## 原因与同图对照

旧桥接把两种不同的量混在八张概率图里：学习模型的车辆方向得分，以及被显式置为八方向0分的实测障碍格。规划器对所有低分统一按0.6m半径加栅格余量膨胀。在已训练的整车运动标签下，周围车辆参考位姿的失败得分并非当前车体碰到该处物理障碍的同义词。

追溯同权重训练协议、51×51学生输入与八个方向教师补丁：标签来自整车静态/前进试验，存在教师/学生参考位置偏移，不能当作无车体尺寸的点障碍概率。标签原始逐样本轨迹未完整重建，参考点与物理方向独立标定也尚未补齐；本轮不改偏移、方向次序或训练权重。

在同一停滞快照、同一11.25°/22.5°动作库上，只把低分查询改成参考格检查，保留原0.6m缺测、物理障碍膨胀及0.5硬门槛：原来8个2m环形目标全失败，改后其中6个目标可达，6种搜索配置均得到相同6个出口。它证实旧概率聚合规则可以封住该图中的出口；不是实际车辆安全通过的真值验证。

旧录包没有独立障碍层，同图对照以原桥接“八方向严格为0”的显式覆盖值重建障碍掩码，保守保留它们；不把这种重建用于新的在线导航。

## 本轮修改

- 桥接显式发布ht_obstacle，保留原来的障碍高度、八方向置零与观测支撑层。
- 新configuration接口在车辆参考格查询方向HT得分，低于0.5仍直接拒绝；物理障碍及观测缺失仍按0.6m半径检查。逐格路径、转向跨通道、实际指令弧和独立TARE碰撞检查保持。
- 配置模式必须同时收到观测支撑层、合法二值障碍层，缺任一层就拒绝地图。未预测的当前参考位置不会直接放行；不豁免被拒起点。
- 核心默认point模式保留旧点概率接口，供历史回归和显式点图使用。仿真trial及当前HT配置显式选择configuration，不能靠缺失图层隐式切换。
- 录像快照保留新障碍层，图表根据当轮manifest选择正确的硬门槛公式；避免用旧膨胀公式画新接口的图。
- 新增邻近车辆得分与实测障碍的对照、物理缺测、未预测位置、缺少接口字段、真实停滞快照和执行端停车的回归。
- 新的执行回归发现：启动先验分支用神经预测代替物理观测检查，物理缺测且HT仍有效时可能误放行。现在缓存并逐格检查真实观测支撑；先验半径外的缺测不能靠有效HT预测绕过，扫描范围也与预计算足迹核一致。

统一足迹核后，旧0.25m粗网格测试中x=0.3m不再完全位于1.2m启动先验内：核触及世界格心(1.125,0.625)m，距原点约1.287m。回归改为x=0.1m允许，并新增x=0.3m拒绝断言；不为迁就旧预期而缩小核。这个启动问题是额外发现，不能用于解释已超过启动阶段的74秒停车。

保留32航向和混合动作、控制器、模型与高程融合；不降低概率阈值、不缩小物理足迹、不放宽3秒时效。修改后冻结代码，按AGENTS约定完整测试600秒并与旧三轮对比。若再停住，仍保留失败结果，不将单张地图的出口恢复当成闭环稳定通过。
