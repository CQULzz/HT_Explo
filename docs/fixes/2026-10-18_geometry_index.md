# 连续碰撞查询索引与搜索终止诊断（候选27）

阶段26仍在约505秒后停止移动；末态HT根节点已知、几何根节点无碰撞，但此前记录缺少完整碰撞点云，不能断言唯一原因。失败搜索接近单目标0.15秒预算，需区分超时、空间耗尽、扩展上限与其他硬约束。

## 改动与边界

连续碰撞判定原来每次查询检索三维邻域，再判断水平半径和上下高度。现按本周期真实车体高度先筛选障碍，建立XY索引：查询高度完全相同时用最近邻判断；不同高度及浮点边界回退原始三维判断。原有0.5米碰撞余量、半格对角线余量、上下高度阈值、禁行区和未知拒绝均保留，HT阈值、搜索预算、动作分辨率和速度不变。

添加逐目标终止原因、几何耗时和各硬约束拒绝计数；完整记录碰撞点云及候选视点。手工证据采集改用与发布端匹配的可靠订阅。这些日志、录包开销计入实测。

## 已完成验证

- 真实静态碰撞点云6561个固定查询，重复3次，所有输出逐字节等于旧实现；碰撞1614个。平均耗时从约0.1293秒降到0.03518秒，查询微基准约3.68倍。不能据此声称整车规划加速3.68倍。
- 800组高度、非对称上下界及半径浮点边界对照；真实旧根节点回归；搜索不同退出原因回归。
- 全部4个CTest目标通过，保留日志与基准源码、旧实现、输出和校验值于同目录evidence。
