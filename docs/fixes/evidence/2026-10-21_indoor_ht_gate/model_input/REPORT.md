3. 将记录的51×51输入块重新送入当前 CPU 模型，各点八通道概率与记录误差最大约3.3e-7。加载后梯度卷积核与固定 `GRADIENT_KERNEL` 的最大误差为0，模型处于eval模式。该样本未发现模型加载、dense输出裁剪位置或概率排列的重放不一致。
4. 从同戳 `history_elevation_raw` 和 `history_variance` 重跑 `preprocess_elevation`，与记录的过滤高程最大误差为0。当前过滤器只平滑3×3全部已观测、且无7.5cm高度边缘的单元；孔洞边缘保持原值。
5. 下面两个点的完整51×51输入范围内没有障碍上下文或质量拒绝（独立统计见 `../indoor_completion/inference_patch_statistics.json`）。输入仅为约8cm峰峰值的小幅高度纹理：

6. `prepare_ht_context` 对缺失位置采用最近邻高度填充模型输入。`physical_support = near & ~uncertain` 的near条件是距known单元不超过0.25m；它包含短距离填补位置，并不等于逐格真实observed。发布 `ht_elevation` 时却读取未填补的 `elevation`。因此 `ht_valid=1`、`ht_observation_valid=1`、`ht_obstacle=0` 同时 `ht_elevation=NaN` 可以由现有代码直接产生，不需要假设GridMap错位。是否把这种“近邻支持”命名/对外当作真实观测合理，仍需单独决定；本次未修改。
7. 当前梯度归一化是相邻高度差除以0.115837m，无min-max/逐帧范围缩放。桥接接受0.040–0.042m分辨率，输入291×291、输出241×241、51×51感受野，裁剪25格；记录分辨率约0.04093567m。训练时分辨率/噪声分布的原始契约未找到，不能据这些部署代码宣称已验证训练尺度。

## 离线消融与解释界限

仅对保存的输入做数值干预，没有应用到导航：

- 所有高度加10m后，各点概率差约1e-6到4.3e-6：绝对地面高度零点不能解释该样本低分。
- 上述两个无障碍RF原输入maxP为0.327/0.331；把绝对值小于0.075m的高度改为0后，maxP接近1。裁剪仅高于0.1m的部分对这两个点的输出无影响，因为它们原本没有高墙。
- 对(3.15,5.55)把全部高度乘0.5可使maxP约0.829；乘2则约0.075。这说明模型对厘米级纹理幅度敏感，不能据此把在线梯度或所有地形高度缩小。
- 八方向全部偏低的门点，不会因单纯交换通道/调整heading offset而获得更高的“八方向最大概率”。原始方向标定仍是独立契约，不由本诊断证明。

**推测：** 稀疏观测、最近邻填补和孔边未被滤波的厘米级起伏形成高频梯度，使模型把真实平地输入当作难通过纹理。上述后续样本支持这个机制，但尚未完整重建t13.512s触发帧的前端历史状态，不能宣称精确触发链已全部还原。

**待确认：** 噪声最早来自仿真点云、变换/扫描拼接、CuPy分格/Kalman、历史融合/重采样中的哪一段；训练噪声分布与部署输入是否一致；网络对实测小台阶/坡面所需的噪声阈值。此处没有足够原始逐帧输入确认这些问题。

## 后续独立候选的假设与反例

本轮短前缀修复的600s车库测量期间不运行本目录的模型推理或全量bag重放，不混入输入修改。

可研究的后续假设：只在已有真实观测位置、利用测量方差和局部一致支持估计有限幅度的去噪；孔洞继续保持未知，实测障碍与拒绝掩码继续独立保留。可比较“允许缺少部分邻居但有足够同面样本”的保边滤波与当前必须9/9观测的规则，或者改进具有真实逐点时间的多帧融合。模型仍接收米制高度和原分辨率，HT门槛保持不变。

必须覆盖的反例/验收：

- 真实连续坡面：保留斜率，不能吸附成水平面。
- 实测7.5cm及以上台阶、窄柱和障碍边缘：位置/高度与硬占据掩码不得被滤低或抹除。
- 小于7.5cm但真实存在的门槛/窄凸起：不能因“数值小”就归零；必须依赖空间/时间/方差证据区分。
- 孔洞、无回波和不同楼层：不创造观测，不用真值填补，不跨楼层融合。
- 单细胞高置信障碍与高不确定离群点：分类/保留规则明确，不能同一套强平滑全部当作噪声。
- 用同一输入样本比较去噪前后实际高度误差与HT输出，同时保留其他场景和已知障碍的反例；之后另冻结版本并完整600s同条件测试、保留并上传数据。
