## 修复及实验结论

实际执行修复提交是 `7957e72`。HT局部执行改为按朝向检查矩形车体与原始占用，并保留运动扫掠、HT分数、观测支持、边界和时效检查；恢复使用制动距离收敛及无进展退出。没有清空当前位置障碍、降低HT门限或修改模型权重。TARE探索/完成逻辑未修改，仅有参数声明兼容补丁和只读诊断日志。
