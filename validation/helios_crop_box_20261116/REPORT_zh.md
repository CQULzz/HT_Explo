# Helios32 整车外接框裁剪

用户要求先改为外接框裁剪、尝试并上传分支和标签。本次沿用
`fix/ht-execution-20261113`，计划标签 `ht-helios-crop-box-20261116-v1`。

默认生成 `crop_box` 资产：整车 visual 保留，移除新资产中的车体 collision，
按 URDF 全部 visual/collision 的并集外接框删除回波端点。旧资产不覆盖；
`--self-filter collision_identity` 可在新目录生成旧的完整遮挡模式。
旧 SDF 未设置过滤模式时，新插件仍使用 collision_identity。

base_link 下包络约 0.930×0.700×0.885m；转换到雷达光学坐标后：

- 最小 XYZ：(-0.6374301, -0.3497950, -0.8488843)m。
- 最大 XYZ：(0.2924308, 0.3497950, 0.03650005)m。
- 边界包含，不额外膨胀。框内 XYZ 置 NaN，框外值、帧、时间戳和组织形式保留。

该模式不模拟车体阴影：透过透明车体看到的外部地面，只要在框外就会保留。
整车框内真实外部障碍也会被裁掉。这是用户指定的几何近似，不能作为实车近地缺测
解决或安全验收结论。规划执行包络、HT 门限、TTL、TARE 策略保持原值。
