# 道路通过性评测：固定脚本，无需每次调用 AI

车库覆盖率不是通过性筛选的主指标。本目录把评价拆开：

1. **输入概率是否能区分危险/可通行路段**：危险误放行率、可通行误拒绝率、precision/recall/F1、未知比例、阈值扫描和分场景统计。
2. **规划代价是否把路线引向可通行区域**：危险路线选择、危险路段长度、有安全路线却拒绝、相对最短安全路线的绕行倍数。关闭 HT、HT 权重 0/0.5/1/2/5 同批比较。
3. **车辆是否真正通过**：需要真实模型输出、车体参数和非平坦物理仿真/实测；本工具不把前两项冒充第三项。

## 一条命令

在仓库根目录执行：

```bash
bash experiments/traversability/run.sh
```

依赖仅为 Python 3 标准库及支持 C++17 的 `c++` 编译器。首次自动编译适配器，之后按源码哈希复用缓存；不启动 ROS/Gazebo，不调用模型/API，不进行逐帧交互。输出自动覆盖，可用 `--output /your/run_dir` 分开归档。不要并发写同一目录。

- `results/REPORT.md`：自动报告。
- `results/decisions.csv`：逐任务、逐权重的路线选择、危险暴露和绕行倍数。
- `results/summary.json`：汇总、阈值扫描、分场景混淆矩阵、代码/真实输入校验值。
- `results/fixtures.json`：可复查的全部合成路段和 C++ 评分。
- `results/classification_samples.csv`：分类评分的逐样本输入与独立标签。

```bash
python3 -m unittest discover -s experiments/traversability -p 'test_*.py' -v
```

## 真实数据直接接入

准备 CSV，字段如下。标签应来自独立的实车通过结果、人工标注或已标定的车辆物理限制，不能直接由预测概率反推出标签。

```csv
sample_id,scenario_id,heading_deg,p,label
patch_001,uphill,0,0.82,0
patch_001,uphill,180,0.91,1
patch_002,steps,0,0.10,0
patch_003,flat,0,,1
```

`label=1` 表示可通行，`0` 表示危险；空概率表示未知。`sample_id + scenario_id + heading_deg` 不得重复。示例数值只说明格式。

```bash
bash experiments/traversability/run.sh --predictions /path/labeled_ht.csv --output /path/evaluation
```

此时**分类指标来自你的 CSV**，路线代价测试仍使用合成路段，报告会分别标明来源。CSV 不包含地图连通关系，不能从它推造车辆路线或通过结果。
先按场景划分独立标定/测试集，在标定集选阈值，再固定阈值评价测试集。只报总体 F1 会掩盖危险误放行，必须同时查看危险误放行率和分场景结果。

## 合成路段覆盖的情况与限制

包含平坦控制组、22° 上/下坡（反向通行能力不同）、18° 横坡、0.30 m 台阶、0.20 m 粗糙度、未知路段、只有危险路、错误高概率和错误低概率。每类 8 种方位、正反向，共 144 个确定性任务。

`config.json` 中车辆限制是**示例测试假设，并非你的车辆标定值**。几何标签独立于 P，但 P 是人为指定的测试输入，不是模型预测；合成分类得分没有模型精度含义。旋转/反向变体不能冒充独立真实样本。

`core_bridge.cpp` 直接调用仓库的 `ht_cost_ns::segment()` 与 `Cost::total()`；Python 不重新实现风险积分。每个路段抽象为均匀概率区域，已知条件仅作抽象数据门控。没有执行完整图构建、TSP、ROS 的 footprint/视线/碰撞检查或车辆动力学。

**当前代码是软风险代价，不是低概率硬拒绝器。** 权重再高，也可能在“只有危险路线”或错误高概率输入时选危险路；提高权重还会改变已知与未知路线的相对代价。固定测试刻意保留这些失败，不通过调参把它们从统计中删除。

若你的产品要求“危险路一定拒绝”，需要单独定义并标定硬阈值、车体覆盖范围、未知处理和无安全路时的停步策略，再用本工具及物理场景回归。此次没有擅自把示例阈值写进生产规划器。

## 节省额度的使用方式

之后改参数/代码后，自己运行上述命令即可得到全套数据，不需要 AI 陪跑。需要分析时只提供 `REPORT.md` 与失败任务对应的几行 CSV；只有新增故障才读原始大日志。之前的车库长实验保留作运动回归，不再当作通过性能力证据。
